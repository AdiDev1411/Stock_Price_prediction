# 📈 Stock Market Prediction Using Machine Learning

## 📌 Project Overview

This project is a **Machine Learning-based Stock Market Prediction System** that predicts whether a stock should be **BUY** or **SELL** using historical stock market data and technical indicators. The application provides an interactive **Streamlit dashboard** where users can dynamically select stock symbols (such as AAPL, GOOG, TSLA, MSFT, etc.) and view real-time stock information along with model predictions.

The system uses **Yahoo Finance** to fetch stock data, calculates technical indicators such as **RSI** and **MACD**, and applies an **XGBoost Classifier** to generate predictions. This project serves as a foundation that can be extended with **News Sentiment Analysis (FinBERT)** and **LSTM** models for improved forecasting accuracy.

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/AdiDev1411/Stock_Price_prediction.git
```

### 2️⃣ Navigate to the Project

```bash
cd Stock_Price_prediction
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux/macOS

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

Open your browser and visit:

```text
http://localhost:8501
```
